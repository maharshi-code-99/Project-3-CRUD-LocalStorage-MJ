# Project No: 3 - React CRUD with LocalStorage

A complete CRUD (Create, Read, Update, Delete) application in React that saves data persistently in the browser's `localStorage` and displays records in a clean table layout.

## Features
- **Create:** Add new user records (Name, Email, Role)
- **Read:** View all records dynamically inside a responsive table
- **Update:** Edit existing rows directly through the form
- **Delete:** Remove records immediately
- **LocalStorage Sync:** Data remains saved even after page refresh
